# Приём заявок с сайта

Две серверные функции. Они получают **копию** заявки: основной путь клиента не
меняется — форма по-прежнему открывает WhatsApp мастерской, и если эти функции
недоступны, заявка всё равно уходит туда.

| Маршрут | Что делает |
|---|---|
| `POST /api/lead` | Принимает заявку, присылает уведомление в Telegram, пишет строку в Google-таблицу |
| `POST /api/telegram` | Вебхук бота: нажатия кнопок и ответы с суммой заказа |

Обработчики лежат в `_lib.ts` — Vercel не делает из этого файла отдельный маршрут.

## Переменные окружения

Задаются в настройках проекта на Vercel (Settings → Environment Variables).
Ни одна из них не попадает в клиентский код.

| Переменная | Обязательна | Назначение |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | да | Токен бота из `@BotFather` |
| `TELEGRAM_CHAT_ID` | да | Чат, куда слать уведомления. Бот принимает команды только из него |
| `TELEGRAM_WEBHOOK_SECRET` | да | Случайная строка. Проверяется в заголовке `X-Telegram-Bot-Api-Secret-Token` |
| `SHEET_WEBHOOK_URL` | нет | Адрес веб-приложения Apps Script (`tools/google-sheet-webhook.js`) |
| `SHEET_WEBHOOK_SECRET` | нет | Тот же секрет, что в скрипте таблицы |
| `ALLOWED_ORIGIN` | нет | Домен сайта, по умолчанию `https://car-stile.vercel.app` |

Пока токены не заданы, `/api/lead` продолжает отвечать `200` и принимает заявку,
но только помечает её как неотправленную (`notified: false`) — сайт не ломается.

## Защита

- Предполётный CORS-запрос: тело принимается только как `application/json`.
- Скрытое поле-приманка `company` — боты его заполняют, живые люди нет.
- Ограничение частоты: не больше 6 заявок с одного IP за 10 минут (в памяти
  тёплого экземпляра; холодный старт его сбрасывает — это защита от случайного
  спама, а не от целенаправленной атаки).
- Вебхук бота проверяет секрет и игнорирует всё, что пришло не из чата владельца.

## Проверка

```bash
pnpm run check          # типы, включая api/**
vercel build --prod     # проверяет, что функции собираются
```

Локальный прогон обработчика без реальных токенов: он вернёт `{"ok":true,...}`
с `notified:false`.
