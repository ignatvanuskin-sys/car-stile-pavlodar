## 3. Оговорки по условиям сервисов

1. **Vercel Hobby не предназначен для коммерческих проектов** — по условиям сервиса. Для сайта клиента это формальность, но при росте нагрузки или подключении платежей потребуется Pro ($20/мес) либо переезд на Cloudflare Pages.
2. **Тайлы карты берутся напрямую у 2ГИС**, без договора. Технически работает и стабильно, но правильнее получить официальный ключ в кабинете 2ГИС и перейти на их API — тогда карта будет с SLA и без вопросов по условиям использования. Точка переключения — константы `TWOGIS_TILES` и `TWOGIS_TILE_SUBDOMAINS` в `Home.tsx`.
