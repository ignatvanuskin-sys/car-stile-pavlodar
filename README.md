# Car Stile — сайт мастерской автоухода (Павлодар)

Полноценный лендинг с онлайн-записью: React 19 + Vite 7 + Tailwind 4, компоненты в стиле shadcn/ui.
Заявка не требует бэкенда — форма собирает готовый текст и открывает чат WhatsApp мастерской,
поэтому сайт раздаётся с любого статического хостинга.

## Запуск

```bash
pnpm install
pnpm run dev        # http://localhost:3000
pnpm run build      # сборка в dist/public
pnpm run preview    # локальный просмотр сборки
pnpm run check      # проверка типов (tsc --noEmit)
```

## Деплой

Репозиторий готов к Vercel: `vercel.json` уже описывает сборку.

### Как менять фотографии

Разметка запрашивает картинки по формуле `/img/<база>-<суффикс>-<ширина>.webp`, например
`polish-portrait-760.webp`. Базы: `hero`, `polish`, `interior`, `sound`, `fara`, `salon`, `seats` и
кадры «до/после» `ba-before`, `ba-after`, `ba-before-wide`, `ba-after-wide`.

1. Положите исходники в папку, указанную в `SRC` внутри `tools/generate-images.py`.
2. Поправьте там же словарь `PLAN` (какой исходник идёт в какую базу и какие ширины нужны).
3. Запустите `python tools/generate-images.py`, затем `python tools/check-assets.py` — второй скрипт
   должен ответить «ОТСУТСТВУЮТ: нет» и «не используются вёрсткой: нет».

**Почему это важно:** SPA-фоллбэк отдаёт `index.html` со статусом **200** даже для несуществующего
файла, поэтому битая ссылка на картинку выглядит просто пустым прямоугольником без ошибки в консоли.
`check-assets.py` ловит такие ссылки статически, до деплоя.

## Что нужно уточнить у владельца до публикации

1. Две цены в каталоге 2ГИС обрезаны интерфейсом: детейлинг-мойка («от 12.000…») и химчистка без разбора («от 45…»). На сайте эти позиции стоят как «по расчёту» — выдуманных цифр нет.
2. Актуальность цен 50 000 / 15 000 / 4 000 ₸ и сезонных 6 000 ₸ за консервацию шин (цена из публикации 2025 года).
3. Официальное написание бренда: в источниках встречаются Car Stile, CAR STAIL и имя витрины «kolumb».
4. **Исходник логотипа в большом разрешении.** Присланный файл — всего 150×150 px. Этого хватает на эмблему в шапке (40 px) и на favicon, но для печати, крупного знака в футере или обложек этого мало. Нужен исходник побольше — лучше вектор (SVG / AI / PDF). Тогда эмблему можно будет ставить и в большом размере. Если у бренда заданы фирменные цвета — прислать и их.
5. Состав вариантов химчистки (без разбора / частичный / полный разбор), сроки и условия.
6. Отдельная страница или блок FAQ — в текущей версии FAQ не выводится, хотя вопросы собраны в исследовании.
7. Юридическое наименование/БИН и политика обработки персональных данных (сейчас форма не собирает данные на сервере — заявка уходит в WhatsApp).
8. Разрешение на использование фотографий клиентов.
9. Фотография входа/фасада: в карточке 2ГИС подходящих нет (на имеющихся кадрах крупно видны вывески других организаций), поэтому в блоке «Как нас найти» стоит карта и ориентир.

## Технические решения, о которых стоит знать

- **Запись без бэкенда.** Пять шагов формы собирают заявку, проверяют поля и на последнем шаге открывают WhatsApp с уже заполненным текстом; на экране успеха есть кнопка «Скопировать текст» как запасной путь. Если появится бэкенд, менять нужно только `goNext()` в `Home.tsx`.
- **Цвет.** Дизайн-система взята у референсного проекта, но кислотный лайм полностью выведен: акцент — золото `--accent: #e0b44a` на графите `--ink: #11110f`. Секция «Как это работает» тоже на графите, с золотыми номерами шагов; звёзды рейтинга на светлых карточках используют отдельный токен `--star` (тёмное золото) — чистый `--accent` давал на бумаге около 1.8:1 и читался как бледное пятно.
- **Блок «до/после».** Показывает две реальные разные фотографии багажного отсека, снятые с одного ракурса, — не один кадр с фильтром. Поэтому CSS-фильтры «состаривания» из шаблона удалены: они превратили бы настоящее фото «до» в подделку.
- **Карта 2ГИС.** Настоящая карта 2ГИС на тайлах `tile0..3.maps.2gis.com` через Leaflet: точка 52.28512, 76.950167, зум 16, золотая метка с подписью CAR STILE, подпись «© 2ГИС» со ссылкой на карточку.
  - Почему не виджет в iframe: `widgets.2gis.com/widget?type=firmsonmap` **без ключа кабинета рисует только рамку** — зум и копирайт появляются, а тайлы и метка организации нет. Посетитель видит пустую плашку, что хуже обычной карты. Проверено на живом браузере.
  - Leaflet подключён **динамическим импортом** (отдельный чанк ≈150 КБ, gzip 44 КБ) и загружается только когда блок контактов подходит к экрану, поэтому первая загрузка не потяжелела. Тайлы приглушены фильтром `saturate(0.62)`, чтобы зелень карты не спорила с тёплой палитрой сайта.
  - **Что стоит сделать перед коммерческим запуском:** тайлы берутся напрямую, без договора с 2ГИС. Правильнее получить официальный ключ в кабинете 2ГИС (`widgets.2gis.com`) — тогда карта идёт через их API, с SLA и без вопросов по условиям использования. Точка переключения — константы `TWOGIS_TILES` и `TWOGIS_TILE_SUBDOMAINS` в `Home.tsx`.
- **Картинки.** Файлы не апскейлятся: ширина всегда не больше исходной. Поэтому `<source>` может запрашивать 1920, а файл быть 1440 — браузер в таком случае просто не растягивает картинку сверх нужного.

## Бренд-ассеты

| Файл | Что это |
|---|---|
| `_brand/logo-src.jpg` | Присланный логотип как есть (150×150). Хранится как источник, в сборку не попадает. |
| `client/public/logo-mark.png` | Эмблема (круглый венок со знаком) на прозрачном фоне, белые линии, 256×256. Используется в шапке (40 px) и футере (52 px). |
| `client/public/favicon.png` | Favicon 192×192 из того же логотипа, с его родной тёмной подложкой — на прозрачном фоне светлые линии пропадали бы в светлой теме браузера. |

Почему эмблема отдельно, а название набрано текстом: внутри логотипа надпись «CAR STILE» занимает всего 11 px по высоте, в интерфейсе она нечитаема. Поэтому в шапке стоит эмблема, а название рядом набрано типографикой сайта — это стандартная связка «знак + словесный логотип», а не перерисовка чужого знака.

Как получить эмблему заново, если придёт файл получше: `.brand` в шапке и футере (`Home.tsx`) подключают `logo-mark.png`; достаточно заменить файл, размеры подставляются через CSS (`.brand__mark`, `.brand--footer .brand__mark`).

## Стоковое фото на первом экране

По просьбе заказчика первый экран закрыт стоковым фото, а не кадром мастерской.

| | |
|---|---|
| Источник | Pexels, фото 29755711 |
| Страница | https://www.pexels.com/photo/29755711/ |
| Лицензия | [Pexels License](https://www.pexels.com/license/) — свободно, в том числе коммерчески, атрибуция не обязательна |
| Файл в проекте | `_stock/hero-gloss-black.jpg` (2560×3837, в сборку не попадает) |

Из шести просмотренных вариантов выбрано это фото по двум причинам. Первая — оно ложится под заголовок «Глянец, чистота и тишина». Вторая — в кадре нет людей и крупных чужих логотипов. Лицензия Pexels прямо запрещает намекать на одобрение со стороны брендов и людей, поэтому варианты с читаемым логотипом BMW на капоте и с лицом мастера пришлось отклонить.

**Что стоит иметь в виду:** на сайте мастерской стоковый автомобиль в шапке читается как «наша работа», хотя это не так. Юридически всё чисто, но по смыслу правильнее заменить его на свой кадр — например, на реальную съёмку после полировки. Когда появится подходящее фото, менять нужно одну строку: источник базы `hero` в `tools/generate-images.py`.

## Версия фото-ассетов

Файлы в `/img` отдаются с заголовком `max-age=31536000, immutable`, а имена у них не хешируются — один и тот же путь живёт годами. Поэтому после **любой** замены фотографии нужно поднять константу `IMG_V` в `Home.tsx` и пересобрать проект: тогда браузеры вернувшихся посетителей запросят картинку заново.

Это не теория: при проверке новый hero не отображался даже после пересборки — браузер отдавал старый файл из кэша по тому же адресу. Именно поэтому в URL картинок появился параметр `?v=2`.
